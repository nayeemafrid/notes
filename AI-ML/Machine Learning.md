- ML is the process of training a piece of software, called a model, to make useful predictions or generate from data. It is a Classical way to teach AI.

# Learns in 3 general ways:

- **Supervised Learning**
- **Unsupervised Learning**: Find hidden patterns in unlabeled data
- **Reinforcement Learning**: Learning by trial and error. Gets rewards or penalties.











Extra info's
- ML evolved into a collection of powerful applications called deep learning ecosystem.
- The foundation for many applications is called a neural network.
- Perceptron is the building block of neural network. It is like a neuron.

New Multi-Layer Perceptron (MLP) has 3 layers:
- **Input Layer**: Takes the input data.
- **Hidden Layer**: Multiplies the input data with **Weight** and **Bias** value
- **Output Layer**: Provides output data.

Deep Learning: Modern way to teach AI

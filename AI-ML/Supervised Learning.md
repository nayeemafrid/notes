Learns with the dataset that has `Label`


**There are 2 types of SL:** Regression & Classification

# Regression
Regression model predicts any number as output.

**Example:**
```
- Future House Price prediction
- Arrival Time Prediction
- Weather model to predict the amount of rain
```

Algorithm used in regression model:

### Linear Regression
To find a straight line to predict exact numbers.

# Classification
Puts things into categories.

Algorithm used in classification model:
- **Logistic Regression/ Sigmoid Function**: Predicting the chance/ percentage of something.
